Set up Claude Code

A one-time install. Do this before the workshop starts so you can build during the 45-minute work block.

1 What you'll need

  • A Claude Pro, Max, or Team account. The free Claude.ai plan won't work for Claude Code.
  • macOS 13+, Windows 10+, or a recent Linux. ~4 GB of RAM.
  • A terminal app you can open (Terminal on Mac, PowerShell on Windows).

2 Download Claude Desktop

The Claude Desktop app gives you a graphical UI you can use alongside Claude Code in the terminal. Download and sign in:

  • claude.ai/download — pick macOS or Windows, install, and open it.

3 Install Claude Code

Open your terminal and run the one command for your operating system.

macOS, Linux, or WSL 
curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell 
irm https://claude.ai/install.ps1 | iex
If neither runs, you may be in the wrong shell. On Windows: PS C:\ in your prompt means PowerShell; just C:\ means CMD — switch to PowerShell.

4 Log in

Open a terminal in any folder and run:

claude

A browser tab will open. Sign in with your Anthropic account, then return to the terminal. You're now in Claude Code.

5 Confirm it works

From a terminal (you can close Claude Code first with /exit), run:

claude --version

You should see a version number print out. If you do, you're set for tomorrow.

Stuck? Run claude doctor for a detailed health check, or see the full docs.

Full setup docs: code.claude.com/docs/en/setup
