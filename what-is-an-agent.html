What is an agent, anyways?

An agent is what happens when an LLM stops talking and starts doing.

An agent is a loop

Strip away the buzzwords and an agent is one thing: a model in a loop with tools.

The agent loop
LLM
Decides what to do next
→
Tool call
Read a calendar. Send an email. Search the web.
→
Result
Feeds back to the LLM
… repeats until the model decides it's done.

The model picks a tool, gets a result, picks the next tool based on that result, and keeps going. It can call one tool. It can call twenty. Whatever the task needs.

Agents do things. Assistants describe things.

This is the difference that matters.

Assistant

"How should I respond to this email?"

It gives you a draft. You copy, paste, edit, send.

Agent

"Triage my inbox."

It reads your inbox, drafts replies for the ones that need them, labels the rest, and tells you what's left.

An assistant tells you what to do. An agent does it.

Tools come from connectors

An LLM on its own can't read your calendar, send a message, or open a file. It needs tools — and tools come from connectors.

A connector is the bridge between Claude and a real system. Connect Gmail and Claude can read your email. Connect Calendar and it can see your week. Each connection turns a description into an action.

In the Claude desktop app, you turn connectors on with a few clicks. Each one you enable becomes a tool your agents can use.

Connect Claude to your tools

For now, we'll turn on connectors the easy way — through the Claude desktop app (the chat UI). A few clicks, OAuth, done. Later we'll wire these up programmatically so Claude Code can use them from the terminal too.

We'll enable two: Google Calendar and Gmail. Every example agent in Step 3 (meeting prep, Friday wrap-up, morning stylist) uses one or both.

Google Calendar
Read your meetings, find free slots, see what's coming up.
Gmail
Read recent threads, draft replies, search by person or topic.
Google Drive
Read docs, look up files. Optional — turn on if your work lives here.
Web search
On by default. Lets agents look things up — restaurants, prices, news.

Turn them on

  1. Open the Claude desktop app. (If you don't have it: claude.ai/download.)
  2. Click your name in the bottom-left, then Settings.
  3. Go to Connectors.
  4. Find Google Calendar. Click Connect. Sign in with the Google account you actually use.
  5. Do the same for Gmail.
  6. Back in the chat, ask Claude "What's on my calendar today?" — if it answers with real meetings, you're wired up.
Key takeaway An agent is an LLM in a loop with tools. The LLM is the brain; connectors are the hands. Once you give Claude hands, your prompts stop describing work and start triggering it.
